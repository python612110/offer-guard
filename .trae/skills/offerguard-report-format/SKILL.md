# OfferGuard 签约风险报告

使用 `frontend/src/lib/reportPdf.ts` 的正式模板，保留直接下载 PDF 的入口，不提供 TXT、HTML 或打印弹窗作为替代。

1. 用 A4 纵向和一致的页边距。主标题「签约风险审查报告」居中、深绿色；企业与岗位、材料版本、报告编号与生成时间居中排在标题下方。各节标题左对齐、深绿色，正文左对齐，页码居中。
2. 使用项目内置 FandolFang 仿宋字体；仅在字体不含个别字形时用系统 CJK 字体补齐。只加粗主标题、章节标题和每项风险的标题；正文、报告信息、风险标签和页码保持常规字重。标题以粗体测宽和绘制。长文本自动换行分页，避免标题或风险标签单独落在页尾。
3. 按「审查范围」「风险明细」组织。每项风险按编号和标题、红色等级与核实状态、风险说明、合同原文及页码、核实建议的顺序展示。红色只用于风险等级与状态，并保留文字标签。
4. 不导出知识库内容、Skill、内部规则编号、模型名称、内部来源或路径。不要删改合同原文；内部审查逻辑保持不变。没有线索时写明本次范围内未发现线索，不替用户作合规结论。
5. 导出当前版本所选报告的全部线索，不受界面筛选影响。用合成材料验证 PDF 下载、仿宋加载、配色、字重、无内部字段，以及长报告自然分页。
