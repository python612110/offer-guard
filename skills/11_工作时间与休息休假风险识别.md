# 工作时间与休息休假风险识别

## 1. 目标
识别应届生就业签约文件中与“工作时间与休息休假风险识别”相关的风险线索，输出可追溯、可解释的 `RiskFinding`。本 Skill 不对未提供的事实作推定。

## 2. 适用范围与关键词
**适用关键词：** 工作时间、工时、加班、调休、休息日、年休假

**重点风险模式：**
工时制度未明确；工作时间、休息日安排不清；加班审批、加班费或调休规则仅笼统引用制度；休假安排与适用规则不明确。

## 3. 识别流程
1. 从 `clauses[]` 中筛选相关条款，并保留原始 `clause_id`、页码和章节路径。
2. 执行硬规则检测：关键词、金额、日期、期限、空白字段、主体名称及跨条款一致性（适用时）。
3. 仅当条款含义依赖上下文、存在模糊措辞或权利义务关系不明确时，执行语义分析。
4. 将命中结果与同一文件其他相关条款交叉核对，避免断章取义。
5. 输出 `RiskFinding`；不能确认的事项标记为“待核实”，并列明缺失信息。

## 4. 规则集
R11-01 工时制度缺失；R11-02 工作时间不清；R11-03 加班处理不清；R11-04 休息日安排不明；R11-05 休假规则外部引用。

## 5. 本 Skill 的判断方法
抽取每日/每周工时、排班、休息日、加班处理和休假表述；涉及特殊工时审批或地区差异时必须检索知识库。

## 6. 风险等级建议
- **高：** 原文直接显示重大经济责任、关键权益放弃或明显不对等安排，且证据充分。
- **中：** 条款关键内容不明确、范围过宽或存在较大争议可能，需要签约前确认。
- **低：** 信息披露或程序性问题，当前材料显示影响有限。
- **待核实：** 缺少合同附件、主体信息、历史事实或知识库依据，不能可靠定性。

风险等级必须结合原文证据确定；不得仅因命中关键词自动判为高风险。

## 7. 输出要求
每个命中项均按 `00_统一规范与接口契约.md` 中的 `RiskFinding` 输出。该 Skill 的 `skill_id` 固定为 `OG-RISK-11`，`risk_type` 使用“工作时间与休息休假风险识别”。

- `evidence`：逐字引用原文，禁止改写或拼接成合同中不存在的句子。
- `triggered_rule`：填写本 Skill 对应规则编号。
- `explanation`：说明原文事实、风险推断及二者区别。
- `suggestion`：要求提供适用工时制度及员工手册相关条款，明确加班审批、加班工资或调休规则，并保留书面确认。
- `student_tip`：“工作需要随时加班”这类表述要问清楚工时制度、加班如何记录和补偿。
- `knowledge_evidence`：当前留空 `[]`；接入知识库后仅填写真实检索结果。
- `confidence`：0 到 1；证据不足时降低置信度。
- `status`：已确认 / 待核实 / 未命中。

## 8. 知识库依赖（预留）
**待知识库模块接入，当前不填写法律依据。**

- 检索主题：工作时间、工时、加班、调休、休息日、年休假
- 建议检索字段：法规/政策名称、条款编号、效力状态、适用地区、发布日期、生效日期、原文片段、来源链接或文档 ID。
- 检索约束：优先适用现行有效且与文件类型、签约时间、适用地区相匹配的依据；无法确认时返回空结果并提示人工核验。

## 9. 误报控制
- 不以单个关键词直接判定违法或无效。
- 不把合同未写明的信息自动视为事实不存在。
- 不把学生尚未提供的附件内容当作合同约定。
- 对简称、别名、模板字段和格式噪声进行上下文确认。
- 若原文不足以支撑风险结论，输出“待核实”或不输出风险项。
