# 押金及培训费风险识别

## 1. 目标
识别应届生就业签约文件中与“押金及培训费风险识别”相关的风险线索，输出可追溯、可解释的 `RiskFinding`。本 Skill 不对未提供的事实作推定。

## 2. 适用范围与关键词
**适用关键词：** 押金、保证金、服装费、工牌费、培训费、违约培训

**重点风险模式：**
要求入职前交押金或保证金；扣留证件；以培训名义收费；培训费、服务期和违约责任约定不清；从工资中扣除费用但未说明依据。

## 3. 识别流程
1. 从 `clauses[]` 中筛选相关条款，并保留原始 `clause_id`、页码和章节路径。
2. 执行硬规则检测：关键词、金额、日期、期限、空白字段、主体名称及跨条款一致性（适用时）。
3. 仅当条款含义依赖上下文、存在模糊措辞或权利义务关系不明确时，执行语义分析。
4. 将命中结果与同一文件其他相关条款交叉核对，避免断章取义。
5. 输出 `RiskFinding`；不能确认的事项标记为“待核实”，并列明缺失信息。

## 4. 规则集
R06-01 入职押金；R06-02 保证金或证件扣留；R06-03 培训收费；R06-04 扣薪抵扣；R06-05 培训服务期关联。

## 5. 本 Skill 的判断方法
金额提取；费用性质分类；识别收款对象、支付时间、退还条件和凭证；区分一般培训与专项培训约定，需知识库核验。

## 6. 风险等级建议
- **高：** 原文直接显示重大经济责任、关键权益放弃或明显不对等安排，且证据充分。
- **中：** 条款关键内容不明确、范围过宽或存在较大争议可能，需要签约前确认。
- **低：** 信息披露或程序性问题，当前材料显示影响有限。
- **待核实：** 缺少合同附件、主体信息、历史事实或知识库依据，不能可靠定性。

风险等级必须结合原文证据确定；不得仅因命中关键词自动判为高风险。

## 7. 输出要求
每个命中项均按 `00_统一规范与接口契约.md` 中的 `RiskFinding` 输出。该 Skill 的 `skill_id` 固定为 `OG-RISK-06`，`risk_type` 使用“押金及培训费风险识别”。

- `evidence`：逐字引用原文，禁止改写或拼接成合同中不存在的句子。
- `triggered_rule`：填写本 Skill 对应规则编号。
- `explanation`：说明原文事实、风险推断及二者区别。
- `suggestion`：不要向个人账户或未核实主体付款；要求提供收费依据、正式票据、退款条件及培训内容；涉及专项培训和服务期时联动对应 Skill。
- `student_tip`：入职前要求交钱、押证件或先转账的情况要格外谨慎，务必保留书面材料和凭证。
- `knowledge_evidence`：当前留空 `[]`；接入知识库后仅填写真实检索结果。
- `confidence`：0 到 1；证据不足时降低置信度。
- `status`：已确认 / 待核实 / 未命中。

## 8. 知识库依赖（预留）
**待知识库模块接入，当前不填写法律依据。**

- 检索主题：押金、保证金、服装费、工牌费、培训费、违约培训
- 建议检索字段：法规/政策名称、条款编号、效力状态、适用地区、发布日期、生效日期、原文片段、来源链接或文档 ID。
- 检索约束：优先适用现行有效且与文件类型、签约时间、适用地区相匹配的依据；无法确认时返回空结果并提示人工核验。

## 9. 误报控制
- 不以单个关键词直接判定违法或无效。
- 不把合同未写明的信息自动视为事实不存在。
- 不把学生尚未提供的附件内容当作合同约定。
- 对简称、别名、模板字段和格式噪声进行上下文确认。
- 若原文不足以支撑风险结论，输出“待核实”或不输出风险项。
