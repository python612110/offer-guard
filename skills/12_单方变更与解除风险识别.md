# 单方变更与解除风险识别

## 1. 目标
识别应届生就业签约文件中与“单方变更与解除风险识别”相关的风险线索，输出可追溯、可解释的 `RiskFinding`。本 Skill 不对未提供的事实作推定。

## 2. 适用范围与关键词
**适用关键词：** 单方调岗、调薪、工作地点、解除、辞退、自动离职

**重点风险模式：**
用人单位可单方调整岗位、薪酬或工作地点且无条件限制；解除条件过于宽泛；员工承担不对等解除责任；以不合理情形视为自动离职。

## 3. 识别流程
1. 从 `clauses[]` 中筛选相关条款，并保留原始 `clause_id`、页码和章节路径。
2. 执行硬规则检测：关键词、金额、日期、期限、空白字段、主体名称及跨条款一致性（适用时）。
3. 仅当条款含义依赖上下文、存在模糊措辞或权利义务关系不明确时，执行语义分析。
4. 将命中结果与同一文件其他相关条款交叉核对，避免断章取义。
5. 输出 `RiskFinding`；不能确认的事项标记为“待核实”，并列明缺失信息。

## 4. 规则集
R12-01 单方调岗权；R12-02 单方调薪权；R12-03 工作地点变更；R12-04 宽泛解除条件；R12-05 自动离职推定；R12-06 责任不对等。

## 5. 本 Skill 的判断方法
识别单方决定权、变更范围、触发条件、通知程序和员工救济表述；结合其他条款判断是否形成实质性权利义务变化。

## 6. 风险等级建议
- **高：** 原文直接显示重大经济责任、关键权益放弃或明显不对等安排，且证据充分。
- **中：** 条款关键内容不明确、范围过宽或存在较大争议可能，需要签约前确认。
- **低：** 信息披露或程序性问题，当前材料显示影响有限。
- **待核实：** 缺少合同附件、主体信息、历史事实或知识库依据，不能可靠定性。

风险等级必须结合原文证据确定；不得仅因命中关键词自动判为高风险。

## 7. 输出要求
每个命中项均按 `00_统一规范与接口契约.md` 中的 `RiskFinding` 输出。该 Skill 的 `skill_id` 固定为 `OG-RISK-12`，`risk_type` 使用“单方变更与解除风险识别”。

- `evidence`：逐字引用原文，禁止改写或拼接成合同中不存在的句子。
- `triggered_rule`：填写本 Skill 对应规则编号。
- `explanation`：说明原文事实、风险推断及二者区别。
- `suggestion`：要求明确变更的合理条件、协商程序、通知方式和异议处理；对“公司有权随时”等绝对化表述要求具体化。
- `student_tip`：重点留意“公司可根据需要随时调整”等句子，问清楚调整范围、条件以及你是否有协商空间。
- `knowledge_evidence`：当前留空 `[]`；接入知识库后仅填写真实检索结果。
- `confidence`：0 到 1；证据不足时降低置信度。
- `status`：已确认 / 待核实 / 未命中。

## 8. 知识库依赖（预留）
**待知识库模块接入，当前不填写法律依据。**

- 检索主题：单方调岗、调薪、工作地点、解除、辞退、自动离职
- 建议检索字段：法规/政策名称、条款编号、效力状态、适用地区、发布日期、生效日期、原文片段、来源链接或文档 ID。
- 检索约束：优先适用现行有效且与文件类型、签约时间、适用地区相匹配的依据；无法确认时返回空结果并提示人工核验。

## 9. 误报控制
- 不以单个关键词直接判定违法或无效。
- 不把合同未写明的信息自动视为事实不存在。
- 不把学生尚未提供的附件内容当作合同约定。
- 对简称、别名、模板字段和格式噪声进行上下文确认。
- 若原文不足以支撑风险结论，输出“待核实”或不输出风险项。
